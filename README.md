# Code-My-Spec/homebrew-mms-agent

Homebrew tap for the [MMS Agent](https://github.com/Code-My-Spec/market_my_spec) binary.

```bash
brew tap Code-My-Spec/mms-agent
brew install mms-agent
```

`Formula/mms-agent.rb` is auto-generated by `.github/workflows/release.yml` in the `market_my_spec` repo on every `v*` tag push.
